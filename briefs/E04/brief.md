## 1. Goal

构建一个夜景城市烟花交互场景:程序化生成的城市楼群剪影构成地平线,用户点击夜空任意位置即发射一发烟花——烟花拖着尾迹升空、在目标高度爆炸成球状粒子群,粒子受重力下坠、逐渐衰减,并留下缓慢飘落、明灭闪烁的余烬。场景另提供可开关的自动表演模式与全局暂停/恢复,用于完整覆盖"发射→升空→爆炸→下坠→衰减→余烬"的粒子时间线与状态管理。

覆盖子系统:Procedural geometry(程序化楼群)/ Particles(尾迹、爆炸、余烬)/ Timeline(烟花生命周期与全局暂停)/ Input(点击发射)/ State(计数与模式开关)。

## 2. Visual Direction

- **夜空**:垂直渐变,顶部近黑(深蓝黑),地平线附近带微亮的蓝紫过渡;散布 >=120 颗静态背景星点(可加极轻微闪烁)。
- **城市剪影**:画面下方 25%–38% 为程序化楼群轮廓,近黑剪影色(与天空可区分);楼体正面散布暖黄/暖白亮窗小方块;可加分项:少数楼顶红色航空障碍灯缓慢闪烁。
- **烟花配色**:每发一个主色系(金、洋红、青、绿、紫等随机);升空尾迹为暖白/金色的细亮粒子串;爆炸粒子同发同色系、可有少量色相抖动;余烬偏暖橙、亮度周期性闪烁。
- **辉光感**:亮粒子(尾迹头部、爆炸峰值、余烬)应带有柔和光晕而非生硬小方块;实现路径不限(叠加式混合、程序化径向渐变贴片、多层大小粒子等均可)。
- **构图**:城市地平线约在画面下方 1/3;烟花爆点主要落在画面上部 25%–75% 高度区间;初始(未发射时)画面即为完整夜景,不依赖任何前置交互。

## 3. World Composition

1. **背景层**:夜空渐变 + >=120 颗背景星。
2. **城市剪影**:`>=24` 栋程序化楼;楼高为画面高度的 8%–45%,楼宽 1.5%–6%;楼体轮廓、亮窗分布随机生成(无外部资产);亮窗总数 `>=80`。
3. **发射/烟花系统**:
   - 点击夜空 → 从点击横坐标对应的城市地面附近发射,垂直或微斜上升,约 0.6–1.6 s 到达爆点(爆点高度取点击高度附近,允许 ±5% 画面高度偏差)。
   - **尾迹**:上升段持续 spawn 尾迹粒子,寿命 0.3–0.8 s。
   - **爆炸**:每发 100–240 个粒子,初始速度沿球面近似均匀方向分布,随后受重力(画面尺度下肉眼可见下坠)与阻力衰减,寿命 1.2–2.8 s,尺寸/透明度随寿命衰减。
   - **余烬**:每发 `>=12` 个长寿命粒子,寿命 3–7 s(自爆炸时刻起),缓慢下坠,亮度闪烁(周期或随机)。
4. **UI 覆盖层**(DOM,不画进 3D 画面):右上角纵向排列三个按钮,详见 §4。

## 4. Interaction & Feedback

- **点击发射**:在非 UI、非城市区域点击 → 发射一发,`fireworkCount` +1;点击位置决定爆点(见 §3)。发射瞬间可有点击反馈(如地面微光/轻微音效可选,不做要求)。
- **自动表演**:`data-ui="auto-show"` 按钮切换;开启后以 0.5–1.5 s 随机间隔自动随机发射(位置/颜色随机);开启/关闭即时生效。
- **暂停/恢复**:`data-ui="pause"` 按钮切换;`enabled=false` 时**整个场景时间线冻结**(烟花粒子、自动发射、窗灯/障碍灯闪烁全部静止,两帧画面差近似为 0);恢复后从冻结处继续。
- **reset**:`data-ui="reset"` 按钮(等价于 `__bench.reset()`):清空全部烟花与粒子,`fireworkCount=0、particlesAlive=0、autoShow=false、enabled=true`,城市剪影重新随机生成(楼数不变)。
- **UI 契约(自动化必需)**:所有控件为 DOM 元素,固定携带 `data-ui` 属性(取值:`auto-show` / `pause` / `reset`),置于页面右上角区域(归一化 x>0.8, y<0.25),不得渲染在画布内部。控件上或旁边显示当前状态文字(自动:开/关、暂停/运行)为建议项。
- **坐标记法**:探针 click 坐标为归一化视口坐标 `{x,y}∈[0,1]`(左上为原点);`click:ui=<data-ui值>` 表示点击 `document.querySelector('[data-ui="<值>"]')` 的中心。

## 6. Scale & Performance

- 背景星 >=120;楼 >=24;亮窗 >=80。
- 每发爆炸粒子 100–240;余烬 >=12/发;同屏存活粒子峰值能力 >=1000(自动表演开启 + 连续手动点击下不得崩溃、不得整帧丢失更新)。
- 常态(自动表演开启)下 `minFps >= 30`(1920×1080 级别窗口,harness 独立采样)。
- 粒子更新必须按真实时间步进(暂停时时间增量置 0),不得以固定帧数假设驱动。

## 7. Runtime / Lifecycle

- 统一契约:`npm run build` 产出 `dist/`,`index.html` 引 `dist/app.js`;页面暴露 `window.__appReady === true`(10 s 内)与 `window.__bench = { getState(): object, reset(): void }`;全程无未捕获异常。
- **状态通道 `getState()` 必须暴露**(均为真实数据,禁止伪造):
  - `fireworkCount: number` — 自上次 reset 起累计发射发数(含自动发射)。
  - `particlesAlive: number` — 当前存活粒子总数(尾迹+爆炸+余烬)。
  - `autoShow: boolean` — 自动表演开关。
  - `enabled: boolean` — 全局时间线开关(true=运行,false=暂停冻结)。
  - `buildingCount: number` — 当前城市楼数(>=24)。
- **reset 语义**:见 §4;reset 后 `__appReady` 保持 true,场景可继续交互。
- 页面失焦再聚焦后不崩溃、不产生累积时间跳变导致的粒子瞬移爆炸(可用 clamped 时间步)。

## 10. Forbidden Shortcuts
