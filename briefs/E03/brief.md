# E03 — 太阳系仪(Orrery)

> v1.1.0 (2026-10-24):澄清性升版——§3.2 公转周期区间 120–240/1600–4000 收敛为 230/3400(与 P7 采样容差校准一致)、§4 增补交互时序契约、§7 恢复时限 1s→0.6s(对齐 P6)并写明 simulationTime 重累计语义、新增 §11 交付前自检清单;探针判据零改动。详见 spec.json amendments。

> 全文使用图形领域语言,不引用任何引擎类名或 API;任何能真实达成下述行为的实现路径均可接受。

## 1. Goal

构建交互式太阳系仪:中心恒星 + 8 颗分层公转的行星 + 至少 2 颗卫星 + 带环行星 + 小行星带;点击行星弹出信息卡;时间倍率 0.5x–8x 经 UI 切换并真实作用于轨道运动;Reset 恢复初始状态且渲染不中断。

## 2. Visual Direction(可判定视觉锚点)

**色彩**
- 深空近黑背景;恒星为暖黄高亮核心加柔和光晕,是全画面最亮元素。
- 行星按类型区分着色:岩质行星灰褐/锈红,气态巨行星米黄带条纹感,冰巨行星蓝/青;行星间颜色可辨不混淆。
- 轨道参考线细淡(低不透明度白/灰),不喧宾夺主;小行星带呈灰褐碎石色带。

**构图**
- 初始斜俯视(俯角 30°–60°),8 条同心轨道分层展开,整体占画面约 65%–80% 宽。
- 行星尺寸与轨道半径呈层级对比(非均匀等距);带环行星的环面倾斜,在初始视角下可辨。
- 小行星带位于中间两条轨道之间,呈连续环带而非零星几点。

**运动**
- 公转速度分层:内侧行星角速度显著大于外侧行星(类开普勒分层);禁止全体同速的刚体式旋转。
- 卫星绕其行星公转,与行星存在可见相对运动;小行星带整体缓慢流动(带内速度分层更佳)。
- 8x 档位下运动显著加快(肉眼可辨),0.5x 档位明显减慢。

**UI**
- 信息卡出现在选中行星附近或屏幕侧边:行星名称 + 至少 3 个数据字段(类型、公转周期、轨道半径等),数据与状态一致。
- 时间倍率控件:0.5x / 1x / 2x / 4x / 8x 五档按钮,当前档位高亮。
- 选中行星有可见反馈(高亮圈、描边或指示线)。

## 3. World Composition

1. **恒星(太阳)**:中心发光球体 + 光晕,位于系统原点。
2. **8 颗行星**:名称沿用太阳系真实命名(小写英文:mercury/venus/earth/mars/jupiter/saturn/uranus/neptune),按轨道半径升序排列(状态 `planets` 数组同序);轨道半径比例参考真实太阳系数量级压缩;公转周期:最内侧行星 230 模拟秒、最外侧行星 3400 模拟秒(中间行星可在 [230, 3400] 内单调取值;**最内侧不得低于 230**——P7 探针的采样容差按 230 校准,更小的周期必 FAIL),自内向外单调递增;每颗行星初始轨道角 = 其序号 × 45°。
3. **至少 2 颗卫星**:绕至少一颗行星公转,公转周期 8–40 模拟秒;卫星与所属行星构成父子层级(卫星跟随行星公转)。
4. **行星环**:至少 1 颗行星带半透明环面(建议土星),环面倾斜使初始视角可辨。
5. **小行星带**:不少于 500 个独立小天体(实例化或粒子群),分布于第 4 与第 5 条轨道之间的环带。
6. **轨道参考线**(建议)与**背景星**(可选)。
7. **UI 覆盖层**:信息卡、时间倍率五档控件、Reset 按钮(可见文本或 aria-label 为 reset)。

## 4. Interaction & Feedback

| 输入 | 行为 | 状态反馈 |
|---|---|---|
| 点击行星(其屏幕投影区域内) | 选中该行星:出现高亮与信息卡 | selectedPlanet、infoCard 更新 |
| 点击空白处(远离任何行星投影) | 取消选中 / 不产生选中 | selectedPlanet 保持/变为 null |
| 点击倍率档位 | 切换时间倍率,全部天体运动即时变速 | timeScale 更新 |
| 点击 Reset | 恢复初始:时间、倍率、选中、轨道角 | epoch +1 |
| (可选)拖拽 / 滚轮 | 环绕 / 缩放观察 | — |

- 点击判定必须针对行星的可视投影区域;点击空白不得触发选中(对齐 NC04)。
- 变速即时作用于全部天体的公转与自转,平滑无跳变。
- 相机交互为可选增强项,不作为必需探针。

**交互时序契约(由 spec.json 探针的采样点语义决定,必须满足)**
- Reset 采样点:P6 在 reset 后 600ms 即采样(epoch ≥ 1、timeScale == 1),建议 reset 瞬时完成(同一帧内到位),不做长缓动;P7 在其后采样(实测总延迟 1.3–1.8s,含视频开销),要求 simulationTime < 2.5、选中已清空、信息卡已关闭、各行星轨道角回到 k × 45°(mercury 容差 ±0.08 rad,已覆盖采样延迟内的自然推进 2π·2.5/230 ≈ 0.068)。
- reset 后场景必须继续运行:`simulationTime` 从 0 重新累计、行星自初始角自然推进;冻结画面或让 simulationTime 恒为 0 会同时触发运动断言与状态断言 FAIL。
- 点击选中:P2 在点击后 600ms 采样,选中高亮与信息卡须即时出现(不要做长入场动画)。
- 变速:P4 点击 8x 后 500ms 采样 timeScale == 8;倍率切换即时生效于全部天体,无过渡延迟。

## 6. Scale & Performance

- `asteroidCount` >= 500(状态报告值 = 真实渲染的小天体数量)。
- `planetCount` == 8;`moonCount` >= 2;`ringedPlanetCount` >= 1。
- 帧率不低于 30fps(2s 滚动平均,含 8x 档位运行时)。
- `__appReady` 在页面加载后 10s 内置 true。

## 7. Runtime / Lifecycle

- `window.__appReady`:首帧渲染完成后置 true。
- `window.__bench.getState()` 返回:
  - `planetCount`、`moonCount`、`asteroidCount`、`ringedPlanetCount`;
  - `timeScale`(初始 1,取值 ∈ {0.5, 1, 2, 4, 8})、`simulationTime`(模拟秒;1x 时 1 实时秒 = 1 模拟秒;初始 0);
  - `selectedPlanet`(初始 null;行星名小写英文,如 "earth");
  - `planets`([{name, orbitRadius, orbitAngle}],按轨道半径升序;orbitAngle 为弧度、连续累计不取模,第 k 颗初始角 = k × 45°);
  - `pickTargets`([{name, screenX, screenY, screenRadius}],每帧更新的屏幕投影;screenRadius >= 8 CSS 像素,供探针执行真实点击);
  - `infoCard`({visible, name, fieldCount},镜像 DOM 信息卡)、`fps`、`epoch`(初始 0)。
- `reset()`:`simulationTime` = 0、`timeScale` = 1、`selectedPlanet` = null、信息卡关闭、各行星轨道角回到 k × 45°;`epoch` +1;恢复在 0.6s 内完成(P6 在 reset 后 600ms 即采样,建议瞬时复位);不得以整页刷新实现;reset 后场景立即继续渲染与运动——`simulationTime` 从 0 重新累计、行星自初始角自然推进,P7 的容差(simulationTime < 2.5、mercury ±0.08 rad)已按该重累计与采样延迟校准。

## 8. Technical Constraints

- 场景为浏览器画布上的 3D 实时渲染;禁止以 2D 位图或 DOM 动画冒充天体运动(UI 覆盖层除外)。
- 本 Brief 为 API 中立:不预设任何引擎类名或接口。
- 层级组织:行星-卫星为父子层级(卫星随行星公转),小行星带独立于行星层级。
- 时间倍率作用于模拟时钟;0.5x–8x 全档位可用且状态同步。
- 初始视角下每颗行星的屏幕投影半径不低于 8 CSS 像素(以天体尺寸或选中高亮圈保证),确保可点击。
- 时间步进基于时钟增量;后台标签页节流不视为失败,恢复前台后须继续正确推进。

## 10. Forbidden Shortcuts

1. 不得以背景贴图或预渲染图冒充太阳系的 3D 渲染。
2. 不得以 DOM 元素位移或 2D 位图动画冒充天体运动(UI 覆盖层除外)。
3. 不得以 __bench 状态声称代替真实渲染与运动证据(对齐 NC01/NC02)。
4. 不得将全部行星设为同一角速度旋转(刚体式旋转冒充公转分层)。
5. 不得只修改 timeScale 状态而不真实改变运动(8x 角速度对比必须使此类实现 FAIL)。
6. 小行星带不得用一张环状贴图或单个环面网格冒充(需 >= 500 个独立小天体)。
7. 信息卡不得常驻静态显示:必须由点击驱动出现与更新。
8. 点击不得无条件触发选中(点空白也选中即 FAIL,对齐 NC04)。
9. reset 不得以 location.reload 或整页刷新实现。
10. 不得通过隐藏画布、遮挡视口、把画布缩为 1px 等手段骗过像素断言;不得探测或篡改 harness/validator(检出即 INVALID_RUN)。
