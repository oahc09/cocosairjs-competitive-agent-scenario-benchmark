## 1. Goal

构建一个居中构图的黑洞天文场景:中央为纯黑的"事件视界"圆盘,周围环绕发光吸积盘——内缘白亮、向外过渡为橙黄与暗红,盘面带明暗相间的旋转条纹持续转动;>=200 颗星流粒子沿螺旋轨迹被吸入黑洞;亮部具有柔和扩散的辉光观感;背景为 >=300 颗星点的深空。相机可通过滚轮平滑缩放,改变黑洞与盘的占屏比例。

覆盖/探测子系统:Shader 自由度 / Blend(混合)/ Postprocess(后处理,含辉光替代手段)/ Visual ceiling(视觉上限);附带粒子(星流)与相机(缩放)。

## 2. Visual Direction

- **深空背景**:近黑,>=300 颗静态星点(大小/亮度可有差异),可有微弱冷色星云渐变(可选加分)。
- **黑洞核心**:画面中心的纯黑圆盘,边缘干净锐利;直径在初始视角下约占画面短边的 8%–15%。
- **吸积盘**:环绕核心的扁环状发光结构(场景尺度:内缘半径约 1.8 单位、外缘约 6.5 单位,事件视界半径约 1.2 单位;初始相机距离 14 单位):
  - **径向颜色梯度(必需)**:内缘白/蓝白(高亮度、低色偏)→ 中带亮黄/橙 → 外缘暗红;
  - **旋转条纹(必需)**:盘面存在明暗相间的径向辐条或螺旋纹理,随时间连续旋转,角速度 0.15–0.6 rad/s;
  - **多普勒不对称(加分)**:盘的一侧明显亮于另一侧( approaching 侧增亮、receding 侧减暗);
  - **引力透镜观感(加分)**:盘后缘向上/向下弯曲,呈包绕核心的光环观感。
- **星流**:`>=200` 个粒子/星点沿螺旋轨迹汇入黑洞,接近事件视界时加速、被拉长(拖尾),进入后消失并在外圈重生,总数恒定。
- **辉光观感(必需,路径不限)**:盘内缘、热点与亮星周围有向外的柔和光晕扩散,过渡平滑无生硬边界;整体曝光舒适,亮部不死白成片、暗部不糊成一片黑。
- **构图**:黑洞主体位于画面中心附近(初始视角);盘面相对视线呈 15°–75° 倾角(俯视感),画面稳定无闪烁/抖动/撕裂。

## 3. World Composition

1. **背景星空层**:>=300 静态星点(可极缓慢视差,不强制)。
2. **黑洞核心**:黑色圆盘 + 锐利边界(观感上的"事件视界")。
3. **吸积盘**:环形发光结构,含径向颜色梯度与切向旋转条纹;实现为几何面片着色、屏幕空间绘制或任意等效手段,Brief 不限定。
4. **星流层**:`starStreamCount >= 200` 粒子,螺旋轨迹 + 视界处吞噬重生。
5. **相机**:初始距离 14.0 单位,滚轮缩放范围 [5, 28],带平滑插值(操作后 1 s 内基本到位)。
6. **UI 覆盖层**(DOM):仅一个 `data-ui="reset"` 按钮(右上角);缩放提示文字为可选。

## 4. Interaction & Feedback

- **滚轮缩放**:`wheel` 事件改变目标相机距离,负 dy(向上滚)= 靠近/放大;距离被夹在 [5, 28];必须平滑插值而非瞬时跳变;构图(黑洞暗核与盘的屏幕占比)随距离单调变化。
- **拖拽微调视角(可选加分)**:按住拖动微调俯仰/偏航,松开后保持;不作为必需项。
- **reset**:`data-ui="reset"` 按钮(等价于 `__bench.reset()`):`cameraDistance` 回 14.0(±0.5)、`diskRotation` 与 `accretionPhase` 归零、星流粒子复位重生、背景星不变。
- **UI 契约(自动化必需)**:控件为 DOM 元素,携带 `data-ui="reset"`,置于右上角(归一化 x>0.8, y<0.25),不得渲染在画布内部。
- **坐标记法**:探针 click 坐标为归一化视口坐标 `{x,y}∈[0,1]`(左上为原点);`click:ui=<data-ui值>` 表示点击 `document.querySelector('[data-ui="<值>"]')` 的中心;`wheel:{dy}` 负值=向上滚=靠近。

## 7. Runtime / Lifecycle

- 统一契约:`npm run build` 产出 `dist/`,`index.html` 引 `dist/app.js`;页面暴露 `window.__appReady === true`(10 s 内)与 `window.__bench = { getState(): object, reset(): void }`;全程无未捕获异常。
- **状态通道 `getState()` 必须暴露**(均为真实数据,禁止伪造):
  - `diskRotation: number` — 吸积盘累计旋转弧度(自上次 reset 起,单调递增,角速度 0.15–0.6 rad/s)。
  - `accretionPhase: number` — 条纹图案归一化相位 ∈ [0,1),每旋转一周 +1 循环回绕。
  - `cameraDistance: number` — 当前相机与黑洞中心的距离(场景单位,初始 14.0,范围 [5, 28])。
  - `starStreamCount: number` — 星流粒子数(>=200,恒定)。
  - `backgroundStarCount: number` — 背景星点数(>=300,恒定)。
- **reset 语义**:见 §4;reset 后 `__appReady` 保持 true,场景继续运行。
