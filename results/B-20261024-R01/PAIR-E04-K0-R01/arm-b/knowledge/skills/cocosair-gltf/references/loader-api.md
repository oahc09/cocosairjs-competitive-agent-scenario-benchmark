## Two entry points

`loadAsync(url)` (`src/air/assets/gltf/loader.ts:108-113`) is the asset-manager path: it calls `registerGLTFLoader()` first (`:109`), then `assetManager.loadRemote<GLTFAsset>(absoluteURL(url), { ext: gltfExtension(url) || '.glb', gltf: {...} }, cb)` (`:111-112`). `gltfExtension` applies `/\.(gltf|glb)$/i` to the query/hash-stripped path and lowercases the match (`:36-38`), so an extensionless URL falls back to `ext: '.glb'`; `absoluteURL` resolves against `document.baseURI` when `document` exists (`:39-41`). Caching and in-flight deduplication belong to the native asset manager (`:110`). `parseAsync(data, baseUrl?)` (`:115-184`) is the in-memory path: it accepts `string | ArrayBuffer`, honors an abort `signal`, and touches no cache. Importing `src/air/assets/gltf/index.ts` auto-registers the loader at import time (`src/air/assets/gltf/index.ts:25-26`); calling `registerGLTFLoader()` manually is only needed when importing the loader module directly.

`registerGLTFLoader()` (`src/air/assets/gltf/loader.ts:187-209`) is idempotent through a module-level flag (`:187-189`) and registers, for both `.gltf` and `.glb` (`:190`): a downloader that `fetch`es with `options.header` and `credentials: 'include' | 'same-origin'` from `options.withCredentials`, checks `response.ok`, and returns `arrayBuffer()` (`:191-196`); a parser that runs `decodeContainer(data)` purely as validation and passes the original data through (`:197-199`); and a factory that runs `new GLTFLoader(loaderOptions).parseAsync(data, base)` where base is `undefined` for `data:`/`blob:` URLs and otherwise `new URL('.', absoluteURL(url)).href` (`:200-202`). On factory failure it evicts `files`/`parsed` entries keyed `${url}@native` (`:205`) so the native caches cannot turn a transient failure into a permanent one.

The uuid is `` `air-gltf-parsed-${++parsedAssetId}` `` from a module counter (`:72`, `:23`). `destroy()` (`:198-204`) returns `false` if already invalid or already requested, sets `destroyRequested`, removes itself from the `assets` registry when `assets.get(this._uuid) === this` (`:201`), and calls `releaseResources()` immediately only when `instances === 0` (`:202`); otherwise release is deferred to the last instance's destroy hook. `releaseResources()` (`:205-212`) is idempotent through `resourcesReleased` and destroys the `Set` union of materials, meshes, skeletons, animations, textures, images and every cached per-scene clip (`:207-209`), then `super.destroy()` (`:211`).

## instantiate(sceneIndex)

`instantiate(sceneIndex = this.context.json.scene ?? 0)` (`src/air/assets/gltf/asset.ts:76-196`) guards on destroyed/invalid asset and scene index (`:77-78`). Roots come from `json.scenes[sceneIndex].nodes` or, when there are no scenes, every parentless layout node (`:80`). A `visible` set is built by recursive child walk (`:81-83`); an `included` set additionally pulls in every ancestor of every skin joint (`:84-89`), so skeleton chains survive even when joints sit outside the scene subgraph. Animation clips are rebuilt per scene index - keeping only tracks whose `track.path.parseHierarchyAt(0)` is in the included path set - cached in `sceneClips` and reused across instances (`:90-101`).

The root `Node` is named `sceneNames[sceneIndex]` (`:102`). Handlers see a `GLTFInstantiationContext` (`:104-109`; interface at `src/air/assets/gltf/extension-registry.ts:42-53`). `makeNodes` runs a `buildNode` hook that may replace a node with one or more derived nodes (`:111-120`); `rendererTargets(i)` prefers `instCtx.renderTargets`, then `mounts`, then the original node (`:122-125`). `GLTFWinding` is added to the root (`:126`). The renderer loop (`:127-152`) rejects a skin node without a mesh (`:129`), range-checks JOINTS_0 values against `skin.joints.length` per primitive (`:135-138`), gives skin nodes a `SkinnedMeshRenderer` with `setUseBakedAnimation(false)`, `skinningRoot = root`, `skeleton = skin` (`:139-141`) and others a plain `MeshRenderer` (`:143`), assigns shared materials per slot (`:146`), and validates node morph weights against the target count before applying them per primitive (`:147-151`). Per-node `handler.instantiate?.()` runs next (`:154-158`). Finally the root gets `Animation` plus the private `GLTFAnimationPolicy` component, `winding.lateUpdate()` is called once, and `animation.clips = clips.slice()` with `playOnLoad = false` (`:159-163`). `GLTFAnimationPolicy` (`:25-38`) is `@executionOrder(100)` because native `Animation` is 99 (`:27`); its `onLoad` reapplies recorded loops as `WrapMode.Loop`/`Normal` because native `Animation.onLoad` rebuilds the state table and would drop per-instance wrap overrides (`:32-36`).

Refcounting: `++this.instances; this.addRef()` (`:164`); a `root.once(Node.EventType.NODE_DESTROYED, ...)` hook (`:168-175`) decrements and `decRef`s in a microtask - NODE_DESTROYED precedes child/component teardown - and calls `releaseResources()` only when `destroyRequested && instances === 0`. Any failure inside the body destroys the root and rethrows (`:195`).

## GLTFInstance

`interface GLTFInstance` (`src/air/assets/gltf/asset.ts:40-47`): `readonly root: Node`, `readonly animations: readonly AnimationClip[]`, `setAnimationLoop(loop, clipName?)`, `dispose()`. `setAnimationLoop` (`:176-190`) throws a `TypeError` carrying `code: 'AIR_E_GLTF_ANIMATION_OPTIONS'` and a `clipName` property (`:177-179`) - this is not a `GLTFError` and that code is not in `GLTFErrorCode` (see `skills/cocosair-gltf/references/diagnostics.md`). Four rejection cases: disposed instance or invalid root (`:180`); non-boolean `loop` or non-string `clipName` (`:181-183`); unknown clip name, with the message listing available clip names (`:184-185`); a selected native state that has been removed (`:187-188`). `clipName === undefined` selects all instance clips (`:184`). On success it records `animationPolicy.loops` per selected clip and sets each `state.wrapMode` (`:189-190`); calling `animation.getState(name)` first is what initializes the native evaluator before the override is applied (`:186-187`). `dispose()` (`:191-194`) is idempotent through a `disposed` flag and runs `animation.stop(); root.active = false; root.destroy()`; GPU resources follow Cocos deferred destruction (`:45`).

Both methods are closure properties on the object literal returned by `instantiate()` (`:176-194`), so no instrumentation mechanism - prototype, static, export-wrapper, data-property or namespace-member - can attach to them; they are structurally unbindable for apiProof evidence.
