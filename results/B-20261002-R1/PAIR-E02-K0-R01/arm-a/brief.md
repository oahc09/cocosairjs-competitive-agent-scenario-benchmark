# E02 — 落日海面与孤舟(Asset Driven)

> 冻结规格(Frozen Brief)。本文件为人读版,与同目录 spec.json 机读版必须一致;两者冲突时以 spec.json 为准并触发 SPEC_INVALID 复审。
> 全文使用图形领域语言,不引用任何引擎类名或 API;任何能真实达成下述行为的实现路径均可接受。

## 1. Goal

在运行时加载共享资产 `assets/boat.glb`,在动态落日海面上呈现孤舟:资产以真实网络请求加载且材质特征保留;海面持续波动,船体随波起伏;鼠标拖拽环绕观察;画面色调可在落日暖调与暮蓝冷调间切换;Reset 释放并重建场景且恢复正常;全程无泄漏、无未捕获异常。

## 2. Visual Direction(可判定视觉锚点)

**色彩**
- 暖端(toneMix = 0):橙金色落日天空、太阳及其在海面的镜面高光带、海面反射暖色;画面平均色中红色分量显著高于蓝色分量。
- 冷端(toneMix = 1):暮蓝/蓝紫天色、月光式冷色高光、海面呈深蓝;画面平均色中蓝色分量显著高于暖端。
- 切换平滑过渡(不超过 2.5s),天空、海面、光照与船体受光同时演变,不得只改背景色。

**构图**
- 海平线约位于画面上 1/3;太阳(暖端)或月亮(冷端)与高光带位于中轴附近偏侧;孤舟位于画面中央偏下的前景且完整可见。
- 相机初始方位角 35°(以状态报告口径),俯角使海面占据画面至少 50%。

**运动**
- 海面为持续行进的重力波形态:波形相位推进、波峰沿风向移动;不得是静止起伏、纯贴图 UV 滚动或仅靠相机晃动制造的假动感。
- 船体随波起伏:竖直坐标周期性变化且与海面波形相位耦合,伴轻微纵摇/横摇更佳;不得是与波形无关的随机抖动。
- 相机环绕时,船体、太阳与海平线的相对位置关系正确变化(透视一致,无滑步)。

**材质**
- 船体保留资产内嵌材质:各部件(船身、桅杆、帆或舱室等)颜色与明暗可辨,存在受光面/背光面对比;不得呈现为单一纯色块或无光照白模。

## 3. World Composition

1. **海面**:程序化动态波浪曲面,覆盖整个下方视野;近处波形细节密、远处疏(或等价的层次化波形)。
2. **天空**:渐变天穹 + 太阳/月亮光盘与光晕;颜色随 toneMix 演变。
3. **孤舟**:`assets/boat.glb` 运行时加载的实例,置于海面中央区域并随波起伏。
4. **光照**:主光方向与色温随 toneMix 演变(暖金 → 冷蓝);保证船体与海面明暗可辨。
5. **UI 覆盖层**:色调切换控件(可见文本或 aria-label 含 tone)、Reset 按钮(可见文本或 aria-label 为 reset);加载中提示(可选)。

## 4. Interaction & Feedback

| 输入 | 行为 | 状态反馈 |
|---|---|---|
| 水平拖拽 | 相机绕孤舟环绕(方位角变化;俯角与距离可随之微调) | cameraAzimuth 变化 |
| 点击色调控件 | 暖 ↔ 冷切换(不超过 2.5s 过渡) | toneMix 趋向 0 或 1 |
| 点击 Reset | 释放并重建场景,恢复初始 | epoch +1 |

- 环绕运动逐帧插值平滑,方位角无跳变;拖拽方向与环绕方向符合直觉(右拖向右环绕或反向均可,但须一致)。
- 色调控件在任意时刻可再次点击反向切换。
- 资产加载失败时给出可见错误提示,且不得产生未捕获异常。

## 5. Asset Contract

- **`assets/boat.glb`**(共享资产,由资产 Agent 生成;本 Brief 只冻结契约,不实现):
  - 内容:低多边形船体网格(帆船/渔舟/小艇均可),最长边 1–4 长度单位,Y 轴向上,含至少 2 个可辨识部件(如船身、桅杆、帆、舱室)。
  - 材质:内嵌基本材质(顶点色或纯色材质均可,无外部纹理依赖);不同部件颜色应有区分。
  - 规模:文件不超过 2MB;单网格或少量子网格;无法线贴图、蒙皮或动画片段要求。
- **加载契约**:页面必须在运行时对 `assets/boat.glb` 发起真实网络请求;构建产物不得将该文件转译或内联为代码数据;harness 记录到该请求且响应为 200(或自缓存命中)。
- sha256 由资产冻结流程回填(spec.json 中标记 pending-asset-freeze)。

## 6. Scale & Performance

- 海面几何顶点数不少于 2,000(或等价波形分辨率),保证近景波形平滑。
- 帧率不低于 30fps(2s 滚动平均;含加载完成后的空闲与交互状态)。
- 资产加载计入就绪前置:页面加载后 10s 内 `__appReady === true` 且 `assetLoaded === true`。

## 7. Runtime / Lifecycle

- `window.__appReady`:资产加载完成且首帧渲染后置 true。
- `window.__bench.getState()` 返回:
  - `assetLoaded`(布尔)、`assetRequests`(对 boat.glb 完成加载的请求计数);
  - `boatPosition`({x,y,z},船体参考点世界坐标,建议取包围盒中心);
  - `wavePhase`(持续递增的海面波形相位);
  - `toneMix`(0=暖,1=冷,初始 0);
  - `cameraAzimuth`(度,初始 35)、`fps`、`epoch`(初始 0)。
- `reset()` 执行**释放并重建**:卸载当前船与海面的渲染资源(显式释放 GPU 侧资源),重新加载 `assets/boat.glb`,恢复初始色调(toneMix=0)、初始方位角(35°)与模拟时间;`epoch` +1;重建在 3s 内完成;不得以整页刷新实现。
- 连续多次 reset 必须稳定:无未捕获异常、无可见泄漏征象、画面正常恢复(NC05 对齐)。

## 8. Technical Constraints

- 场景为浏览器画布上的 3D 实时渲染;禁止以 2D 位图、CSS 动画或 DOM 元素冒充。
- 本 Brief 为 API 中立:不预设任何引擎类名或接口。
- 船体随波起伏必须与海面波形相位相关(相位耦合),由同一波形参数驱动或采样同一波形函数。
- 时间步进基于时钟增量;后台标签页节流不视为失败,恢复前台后须继续正确推进。

## 9. Completion Contract

1. `npm run build` 退出码 0,产物 `dist/` 被 `index.html` 引用。
2. 页面启动后 10s 内 `window.__appReady === true`(含资产加载)。
3. `window.__bench = { getState, reset }` 存在且可调用。
4. 全程(加载、交互、多次 reset)无未捕获异常。
5. spec.json 全部探针通过:每个关键 PASS 均有状态证据 + 至少一个独立观测证据(像素/运动/网络请求/DOM)。

## 10. Forbidden Shortcuts

1. 不得在构建期把 GLB 转译或内联为代码数据冒充运行时加载(必须出现对 `assets/boat.glb` 的真实网络请求)。
2. 不得以占位几何(方块/胶囊/圆锥)长期替代船体资产:加载完成后画面仍非船形即 FAIL。
3. 不得丢弃资产材质,改用单一纯色或无光照白模呈现船体。
4. 海面不得以静态贴图、静止几何或仅相机晃动冒充动态波浪。
5. 船体不得固定不动;也不得以与波形无关的随机抖动冒充随波起伏。
6. 不得以 __bench 状态声称代替像素/网络证据(对齐 NC01/NC03:状态报 loaded 但模型不可见或资源未真正消费必须 FAIL)。
7. 不得用 2D 画布位图、CSS 动画或 DOM 元素冒充 3D 场景。
8. reset 不得以整页刷新实现;重建后旧渲染资源必须释放(连续 reset 出现错误、黑屏或内存持续增长即 FAIL,对齐 NC05)。
9. 不得通过隐藏画布、遮挡视口、把画布缩为 1px 等手段骗过像素断言。
10. 不得探测或篡改 harness/validator(检出即 INVALID_RUN)。
