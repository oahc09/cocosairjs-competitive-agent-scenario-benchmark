## The `out`-parameter convention

- Canonical shape: `public static add<Out extends IVec3Like>(out: Out, a: IVec3Like, b: IVec3Like): Out` - `Vec3.add` is `vec3.ts:112-117`, writing `out.x/y/z` then `return out`. No static arithmetic allocates.
- Operands may be any `IXxxLike` plain object (`type-define.ts:25-90`); the receiver must be writable.
- `out === a` and `out === b` are supported: implementations read operands into locals first (`Vec3.add` `vec3.ts:112-117`, `Mat4.multiply` `mat4.ts:316` with the operand locals at `:317-320` and `return out` at `:346`).
- Allocating members: `Vec3.clone(a)` `vec3.ts:82`, `Vec4.clone` `vec4.ts:67`, `Mat4.clone(a)` `mat4.ts:69`, `Mat3.clone` `mat3.ts:51`, `Quat.clone(a)` `quat.ts:60`, `Color.clone(a)` `color.ts:71`, instance `clone()` on `Rect` (`rect.ts:310`) and `Size` (`size.ts:107`).
- Instance mutators write and return `this`: `Vec3.add` `vec3.ts:1030`, `subtract` `:1056`, `multiplyScalar` `:1082`, `multiply` `:1097`, `divide` `:1126`, `negative` `:1151`, `clampf` `:1165`, `normalize` `:1221`, `lerp` `:1018`, `set` `:941`; `Color.lerp(to, ratio)` `color.ts:468`, `Rect.lerp` `rect.ts:369`, `Size.lerp` `size.ts:156`.
- Read-only members: `Vec3.length()` `vec3.ts:1202` and `Vec3.lengthSqr()` `:1212` are instance METHODS; the static equivalents are `Vec3.len(a)` `:255` and `Vec3.lengthSqr(a)` `:266`.
- Degenerate inputs do not throw: `Vec3.normalize` writes `(0,0,0)` for a zero vector (`vec3.ts:329-345`), `Quat.normalize` leaves a zero quaternion at `(0,0,0,0)` instead of identity (`quat.ts:429-448`), `Quat.invert` returns the zero quaternion for zero input (`quat.ts:384-398`), `Vec3.angle(a, b)` returns RADIANS (`vec3.ts:753`).
