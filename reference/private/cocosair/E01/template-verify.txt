【引擎坑位与关键事实记录】(供 harness/reference/后续模板维护参考)
  1. canvas 约束:#GameCanvas 必须在引擎模块 import 前存在于 DOM(pal/screen-adapter 为模块
     顶层单例,import 即绑定)。官方 DOM 结构 GameDiv > Cocos3dGameContainer > GameCanvas。
     本模板 module script 在 DOM 解析完成后执行,天然满足;绝不能动态插入 canvas 后再 import。
  2. 引擎 bundle 为浏览器专用:模块顶层即访问 window.navigator(SystemInfo 单例),
     裸 Node 环境 import 直接 ReferenceError —— 无法在 Node 侧做冒烟,必须真浏览器。
  3. Camera.visibility 必须显式 = Layers.Enum.DEFAULT(4.0-alpha 默认 undefined → 什么都不画)。
  4. 环境光:scene.globals.ambient(HDR 默认 isHDR=true,exposure=1/38400)。
     skyColorHDR 为 AmbientInfo 与渲染场景 Ambient **按引用共享**的 Vec4(Ambient.initialize
     直接赋引用),app.run 后原位 .set() 即生效(examples/render-composite P2a 已验证路径);
     skyIllum 走公开 setter(同步 _resource)。HDR 量级:方向光 illuminance≈50000 lux;
     若误用 LDR 量级(1~900)× exposure ≈ 0 → 不可见。
  5. import map 裸名必须用 "cocosair.js"(npm 包名);引擎仓库 examples 源码内是
     'cocosair'(其私有 dev-server importmap),照抄裸名在 npm 安装场景会 404,需换写。
  6. gltf-decoders 路径解析(任务要求核查项):
     - 引擎模块 cocosair.module.js 内 grep 计数:import.meta 出现 0 次,
       "gltf-decoders" 字符串出现 0 次 → **引擎对 decoder 部署路径零假设,无 import.meta.url
       相对解析逻辑**;
     - decoder 为应用显式注入 provider(GLTFLoader.setMeshoptDecoder(createMeshoptDecoder(…))
       等,见 docs/gltf/gltf-decoder-deployment.md),未用压缩扩展时不加载、无 worker;
     - 故 dist/vendor/gltf-decoders/ 只需保持与 node_modules 相对结构(basis/draco/meshopt
       子目录),应用侧用绝对/相对 URL import('/dist/vendor/gltf-decoders/…')即可;
     - 静态服务 MIME 硬约束已满足:.mjs/.js/.cjs → text/javascript,.wasm → application/wasm
       (instantiateStreaming 前置;serve.mjs 已按引擎部署文档 §3 实现)。
  7. Draco 浏览器边界:随包 draco3d.js 是 Node/CommonJS 形态,浏览器正向解码需应用另配
     factory 注入 —— 与本 smoke 无关(未用压缩),记录备查。
  8. 应用代码顶层 await(es2022)要求 esbuild target ≥ es2022(否则 esbuild 报
     top-level await 不可用);本模板 target=es2022。
  9. 引擎导出面已核对:createAirApp/Scene/Node/Camera/DirectionalLight/MeshRenderer/Layers/
     builtinResMgr/utils/primitives/Vec3/Color/Component/director/Director 均在
     build/npm/cocosair.module.js 的 export 列表(单条巨型 export 语句,共数百导出)。
